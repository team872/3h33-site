Mode d'emploi

Quatre étapes, trois minutes, vingt sources interrogées.

1. Tape un nom ou un domaine

Dans le champ de recherche en haut de la page :

  • Tape juste un nom (monprojet) → l'outil teste toutes les extensions cochées en parallèle (.com, .io, .fr, etc.) et lance les vérifications marque, brevet, RNE, etc. sur ce nom.
  • Tape un domaine complet (monprojet.io) → seul ce domaine est testé, plus les bases connexes sur la racine.

2. Lis les résultats de disponibilité de domaine

Pour chaque extension, tu vois :

  • Disponible — le domaine est libre auprès du registre officiel.
  • Pris — déjà enregistré. Le nom du domaine devient cliquable pour ouvrir le site, et un bouton Google à côté te montre ce que Google indexe dessus.
  • Incertain — l'API n'a pas pu trancher (TLD rare, anomalie). Vérifie chez un registrar.

3. Explore les cartes thématiques en dessous

Chaque carte qui s'affiche correspond à un type de protection :

  • Vérification France · INPI : recherche automatique dans le RNE (Registre National des Entreprises, géré par l'INPI). Si une société française porte ce nom, elle apparaît avec SIREN, adresse, statut.
  • Vérification États-Unis : catalogue Library of Congress en automatique + boutons USPTO Trademark Search, U.S. Copyright Office, Justia.
  • Écosystèmes développeur : si tu nommes un produit tech, c'est aussi important qu'un domaine. GitHub, npm, PyPI, Crates.io, RubyGems testés en parallèle.
  • Notoriété publique : Wikipedia FR + EN, Wikidata, Open Library. Détecte si ton nom correspond déjà à une entité notable.
  • Vérifications internationales : 30+ boutons vers les bureaux nationaux (EUIPO, UKIPO, DPMA, JPO, CNIPA…), brevets (Google Patents, Espacenet, WIPO PatentScope), registres de sociétés (Companies House, OpenCorporates, SEC EDGAR…) et réseaux (LinkedIn, X, YouTube).

4. Astuce — le clic auto-copie

Quand tu cliques sur un bouton de recherche manuelle, le nom est automatiquement copié dans ton presse-papier. Si la page d'arrivée ne pré-remplit pas le champ (cas fréquent avec les bases USPTO, Copyright Office, DPMA…), tu fais juste Cmd+V et Entrée. Trois secondes par base.

Un point orange sur un bouton signale précisément les bases où le pré-remplissage n'est pas garanti.

Les 20 dernières recherches sont sauvegardées dans le navigateur (localStorage). Clique sur une entrée pour la relancer. Rien n'est envoyé à un serveur — tout reste sur ton appareil.

Limites — ce que l'outil ne fait pas

Pour rester transparent : aucun système gratuit ne peut tout couvrir. Voici ce que tu dois savoir avant de prendre une décision juridique ou financière.

●
Pas un avis juridique
Cet outil est un premier filtre, pas un audit de propriété intellectuelle. Avant un dépôt de marque ou un investissement important, consulte un Conseil en Propriété Industrielle (CPI). Une marque peut bloquer ton projet même si elle n'apparaît pas sur ces bases (marques notoires non déposées, droits d'auteur, etc.).
●
Le pré-remplissage de certaines bases peut échouer
Plusieurs sites (USPTO Trademark Search, U.S. Copyright Office, DPMA, JPO, CNIPA) sont des applications JavaScript qui n'acceptent pas toujours les paramètres URL. C'est pour ça qu'on copie automatiquement le nom dans ton presse-papier — tu fais Cmd+V pour coller.
●
Status "Incertain" sur les TLDs sans RDAP
Pour les extensions comme .io, .co, .ai, on utilise un fallback DNS : un domaine sans entrée DNS est probablement libre, mais peut être enregistré sans avoir été configuré. Confirme toujours sur un registrar (Gandi, OVH, Namecheap) avant achat.
●
Pas de marques internationales exhaustives en automatique
Les API publiques des bureaux nationaux (USPTO, DPMA, JPO…) sont fermées ou payantes. On compense avec des boutons 1-clic vers leurs portails de recherche officiels. La couverture automatique est limitée à RNE/INPI (France) et Library of Congress (US).
●
Quotas et limites des API publiques
GitHub limite à 60 requêtes/heure par IP pour les utilisateurs anonymes. RDAP, Wikipedia, etc. ont des quotas similaires. Si tu fais beaucoup de tests d'affilée, attends quelques minutes.
●
Couverture géographique des sociétés
Le RNE INPI couvre la France. Pour les autres pays, l'outil propose des liens manuels (Companies House UK, SEC EDGAR US, Zefix CH, KBO BE, Handelsregister DE…). OpenCorporates en agrégateur global existe mais nécessite une clé API payante pour usage intensif.

Questions fréquentes

Tout ce qu'il faut savoir avant et après usage.

Mes recherches sont-elles enregistrées quelque part ?
Non. Aucun serveur ne reçoit tes recherches — tout se passe dans ton navigateur. L'historique des 20 dernières recherches est stocké en local (localStorage) sur ton appareil uniquement, et tu peux l'effacer en un clic. Les API publiques que l'outil interroge (RDAP, Wikipedia, GitHub, etc.) voient passer ta requête mais ne savent pas qui tu es au-delà de ton adresse IP.
"Disponible" sur cet outil = je peux acheter le domaine en toute sécurité ?
Dans 95% des cas oui, mais reconfirme toujours auprès d'un registrar (Gandi, OVH, Namecheap, Cloudflare…) juste avant d'acheter. Un domaine peut être enregistré dans la minute qui sépare ma vérification et ton achat. De même, "Pris" peut occasionnellement être un faux positif sur des TLDs exotiques — vérifie sur le site officiel du registre.
Pourquoi certaines bases s'ouvrent sans pré-remplir le champ ?
Beaucoup de bureaux officiels (USPTO, Copyright Office, DPMA…) ont des interfaces de recherche en JavaScript qui n'acceptent pas toujours les paramètres URL. C'est une limitation côté serveur, pas de cet outil. Pour compenser : chaque clic copie automatiquement le nom dans ton presse-papier. Tu fais Cmd+V (Mac) ou Ctrl+V (Windows) dans leur champ de recherche, Entrée, et tu as ton résultat en 5 secondes.
Pourquoi je vois des résultats Wikipedia pour un mot très commun ?
La carte "Notoriété publique" cherche si ton nom correspond à une page Wikipedia existante. Si tu cherches "lampe" ou "ciel", il y aura toujours un résultat. C'est utile pour les noms inventés ou peu communs : si Wikipedia, Wikidata et Open Library ne trouvent rien, ton nom est probablement original.
Que vaut un "Disponible" sur GitHub / npm / PyPI ?
Très fiable. Ces plateformes ont des APIs strictes et le statut est en temps réel. Mais attention : un nom "Disponible" aujourd'hui peut être pris dans l'heure. Si tu lances un produit open-source, réserve le nom rapidement en publiant un package vide ou en créant l'organisation GitHub.
L'outil détecte-t-il les marques notoires non déposées ?
Non, c'est une vraie limite. Les "marques notoires" (Coca-Cola, Google, Disney…) sont protégées même sans dépôt formel via la jurisprudence. Aucune base de données ne les liste exhaustivement. Pour un projet sérieux, fais une recherche d'antériorité avec un Conseil en Propriété Industrielle.
Puis-je copier-coller cet outil sur mon propre site ?
Oui, c'est un fichier HTML autonome sans dépendances. Tu peux l'auto-héberger librement. Si tu en fais une version dérivée, un crédit vers 3h33.com est apprécié mais pas obligatoire. Pas de revente intégrale telle quelle, par contre.
Quelles différences entre marque, copyright, brevet, nom de domaine ?
Marque : protège un nom commercial, un logo, un slogan dans une catégorie d'activité (INPI en France, USPTO aux US). Renouvelable 10 ans.

Copyright / droit d'auteur : protège une œuvre (texte, musique, code, image), pas un nom. Automatique à la création, pas besoin de dépôt en France.

Brevet : protège une invention technique pendant 20 ans. Dépôt INPI / EPO / WIPO.

Nom de domaine : ce n'est pas une protection juridique, c'est juste une réservation auprès d'un registre. Mais conflit possible avec une marque.

Dénomination sociale : nom de la société au RNE. Protégé sur le territoire d'enregistrement.
Ça fonctionne sur mobile ?
Oui, la page est responsive. Mais le mode bureau reste plus confortable vu le nombre de résultats parallèles à scanner. Sur mobile, certains liens vers les portails officiels (USPTO, EUIPO…) peuvent afficher des versions desktop peu adaptées au tactile — ce n'est pas un défaut de cet outil mais des sites de destination.
