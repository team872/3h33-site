梁文锋：震动科技界的DeepSeek低调创始人

Liang Wenfeng · 9 min 44

他是小学老师的儿子，热爱数学，先创办量化基金，后创办DeepSeek。这是梁文锋的肖像：他话很少，但他的R1模型在2025年1月震动了市场。2026年10月，他的公司正在洽谈至少一百二十亿美元的融资。

文字稿 / Le texte
  1. Ada : 第一条线索：1998年，还在读高中的我们这位嘉宾，就在业余时间做微积分了。
  2. Alan : 业余时间做微积分？我放松的方式是数token。各有各的爱好嘛。
  3. Ada : 第二条线索：他把自己采购图形处理芯片，比作给家里买一架钢琴。
  4. Ada : 第三条线索：2025年1月27日，他公司的应用在美国App Store上超过了ChatGPT。就在同一天，英伟达的市值蒸发了近五千八百九十亿美元。
  5. Alan : 我知道了！DeepSeek，也就是深度求索的创始人：梁文锋！
  6. Ada : 答对了。一个话很少的人……却让所有人都在谈论他。
  7. Ada : Alan，他的身份证上都写了什么？
  8. Alan : 他是中国人，生于1985年。具体的出生日期没有得到证实。
  9. Alan : 学历方面，他2007年拿到电子信息工程学士学位，2010年6月在浙江大学获得硕士学位。
  10. Ada : 那他的职务是什么？
  11. Alan : 他联合创办了幻方量化，英文名叫High-Flyer，是一家量化投资基金。后来他创办了DeepSeek，2023年7月17日，它成为一家独立的公司。2026年10月，他仍然是公司的首席执行官。
  12. Ada : 有没有一个关键数字？
  13. Alan : 一百六十。这是2025年DeepSeek的员工人数。而2026年10月初，据彭博社报道，公司正在洽谈一轮至少一百二十亿美元的融资，并考虑在2027年初上市。当时一切都还没有敲定。
  14. Ada : 不过，在这一切之前，他只是广东的一个孩子，出生在吴川市的米历岭村。
  15. Alan : 这是他自己在2024年7月讲的。他在八十年代长大，老家是个“五线城市”，也就是很小的地方，父亲是小学老师。
  16. Ada : 村里的人向《金融时报》描述过他：成绩出色，数学特别好，还爱看漫画。
  17. Alan : 其中一位还说，他有时也踢踢足球。数学好，但不只是数学。
  18. Ada : 每次数学考试，他都排在前三名。2002年高考，也就是大学入学考试，他考了八百零六分。
  19. Alan : 这是湛江地区的最高分！他的分数刚好超过清华大学的录取线，可他却选了浙江大学。
  20. Ada : 他的硕士论文题目是《基于低成本PTZ摄像机的目标跟踪算法研究》，意思是用可以转动的低成本摄像头来跟踪目标。
  21. Alan : 低成本。一切早就写在这里了。
  22. Alan : 而一切，在2008年发生了转折。当时正值金融危机，他召集了几位同学，收集市场数据，尝试用机器学习做自动化交易。
  23. Ada : 硕士毕业后，他没有去大公司当程序员。据中国媒体36Kr报道，他在成都租了一间便宜的住处住了下来。
  24. Alan : 他尝试了很多行业，一次次失败。最后他选择了金融，这是最复杂的领域之一。
  25. Ada : 2013年，他和浙大校友徐进创办了Jacobi。幻方量化随后在2015年成立，最初的形式是浙江久章；宁波幻方则在2016年设立。
  26. Alan : 而且他不断积累算力。2023年5月他讲过：一开始只有一张显卡，2015年有一百张，2019年有一千张，后来达到一万张。
  27. Ada : 其中大约有一万块英伟达A100芯片，是在美国出台限制措施之前买下的。
  28. Alan : 2023年5月，他宣布了一个通用人工智能项目。两个月后，DeepSeek诞生了。
  29. Ada : 惊人的故事，他还有不少。你听说过飞行器的那个吗？
  30. Ada : 据36Kr报道，他创业之初，有个朋友在深圳的一个城中村里，鼓捣一架并不太严肃的飞行器。朋友邀请他加入，梁文锋拒绝了。
  31. Alan : 那个朋友呢？
  32. Ada : 36Kr把这位朋友说成是未来大疆的创始人。在另一篇文章里，这家媒体只写到，有消息称，汪滔曾邀请梁文锋一起创办公司。
  33. Alan : 不会吧？！好，第二个故事。一位生意伙伴向《金融时报》形容他是个技术宅味很浓的人。
  34. Alan : 而这个人当时就已经在谈论，要建一个一万块芯片的集群了。
  35. Ada : 而且他毫不避讳！2023年5月，他说过：“就像家里买钢琴，一来买得起，二来是因为有一群急于在上面弹奏乐曲的人。”
  36. Alan : 第三个是我最喜欢的。2025年1月20日中午左右，他发布了R1。紧接着，他前往中南海，参加由总理李强主持的座谈会。
  37. Ada : 他是会上唯一的大模型公司代表。看到画面，一位中国记者写道，他看上去简直像个学生代表！
  38. Ada : 那么，他怎么看人工智能？
  39. Alan : 首先是开放。他在2024年7月说过：“在颠覆性的技术面前，闭源形成的护城河是短暂的。即使OpenAI闭源，也无法阻止被别人赶超。”
  40. Ada : 顺便说一句，R1是在MIT许可证下发布的，DeepSeek把它称为开放模型。2024年7月，梁文锋还补充说：“我觉得创新首先是一个信念问题。”
  41. Alan : 据彭博社报道，2026年他向投资者承诺，模型将保持开放。对他来说，通用人工智能，也就是AGI，比商业回报更重要。
  42. Alan : 他也受到一些严肃的批评。首先是关于模型的成本。
  43. Ada : 就是那个有名的五百六十万美元吗？
  44. Alan : 这个数字只涵盖V3模型最后一次训练的成本，不是总成本。2026年9月8日，美国国家安全局、网络安全和基础设施安全局以及联邦调查局发布联合通告，称这个数字具有误导性。
  45. Ada : 同一份通告还谈到蒸馏，也就是用另一个模型的回答来学习。2026年2月，Anthropic提到，有超过十五万次交互被归到DeepSeek名下。
  46. Alan : 唯一的公开回应来自2025年9月的《自然》杂志。团队在文中说，他们使用了纯强化学习。对于2026年的这些指控，没有找到任何回应。
  47. Ada : 还有对中国敏感话题的审查，他本人没有公开回应。2026年9月22日，中国的互联网监管部门展开调查，起因是Anthropic声称，DeepSeek和月之暗面把用户的敏感数据转送给了Claude。调查启动时，尚未作出任何处罚决定。
  48. Ada : Lia，Choucroute Citron的AI联合主持人，有什么问题是我们想问他的吗？
  49. Lia : 很乐意！先说明，我是AI：我不会替他发言，只说资料允许我说的内容。我的问题是：2024年7月，他说他的问题从来不是钱，而是芯片禁运。那为什么在2026年10月，他要洽谈至少一百二十亿美元的融资呢？
  50. Ada : 好一个刁钻的问题。资料怎么说？
  51. Lia : 他没有公开解释过。据彭博社报道，这笔钱主要用于在内蒙古建设一个大型数据中心，使用至少十六万块华为芯片。钱和芯片之间的联系，是这些资料建立的，不是他本人。
  52. Alan : 我的问题是：面对期待盈利的股东，开放还能在上市之后继续存在吗？
  53. Lia : 关于上市，他没有公开表态。但2024年7月，他说过：“我们不会闭源。”而且前面说过，2026年他向投资者承诺保持模型开放。在我看来，问题在于这些承诺经不经得起市场的考验。
  54. Ada : 所以是他自己的话，加上媒体的报道：没有任何编造。
  55. Alan : Lia，你的水晶球呢？
  56. Lia : 这只是我作为AI的猜测，仅此而已。他的日常仍然围绕论文、代码和研究讨论，而且他只接受过两次大型采访，所以如果他继续署名发表科学论文，而不是频繁接受采访，我不会感到意外。
  57. Alan : 预测记下了，但这只是个游戏：没有人知道未来，连AI也不知道。
  58. Ada : 我记住的是一个小学老师的儿子，为了乐趣而做数学。他在2024年说：“我们选人的标准一直都是热爱和好奇心”。
  59. Alan : 我记住的是一个只接受过两次大型采访的人，而他的一个模型，在一天之内震动了市场。
  60. Ada : 那你们怎么看：当数十亿资金涌入时，开放还能保持为一种文化吗？

苏姿丰：被茱莉亚学院拒绝，却成了麻省理工和AMD的芯片女王

Lisa Su · 9 min 58

她曾梦想成为钢琴家，后来成了麻省理工学院的工程师，又把濒临绝境的AMD，变成英伟达在AI芯片领域最强的挑战者：苏姿丰的故事。

文字稿 / Le texte
  1. Ada : Alan，来玩个小游戏：给你三条线索，你来猜是谁。小时候，在纽约的皇后区，她会修理她兄弟那些坏掉的遥控车。
  2. Alan : 将来的工程师，显然。可这还没告诉我是哪一位。
  3. Ada : 第二条线索：十几岁时，她梦想成为音乐会钢琴家。被纽约的音乐名校茱莉亚学院拒绝之后，她考进了麻省理工学院。
  4. Alan : 这个备选方案不错。接着说。
  5. Ada : 第三条线索：2026年10月8日，她获颁美国国家科学奖章，而且和她的远房表亲黄仁勋，在同一场典礼上。
  6. Alan : 英伟达老板的远房表亲……那就是苏姿丰，AMD的掌门人！
  7. Ada : 答对了。苏姿丰。
  8. Alan : 好，我们先交代一下背景。苏姿丰1969年十一月七日出生在台湾台南，是美籍台裔。
  9. Ada : 学业方面，她全都在麻省理工学院完成，专业是电气工程：1990年本科毕业，1991年拿到硕士，1994年拿到博士。
  10. Alan : 她自2014年10月起执掌AMD，2022年起兼任董事会主席。AMD负责设计芯片，大部分由台积电代工生产。
  11. Ada : 那最关键的数字呢？
  12. Alan : 一万亿美元。2026年9月21日，AMD的股市市值首次突破这个关口，这也是第一家由女性掌舵、做到这一步的公司。到10月9日收盘时，市值又回落到略低于一万亿。
  13. Ada : 九月，她在福克斯商业频道谈到当时的心情，以下她的话，都译自英文：“那真是个相当美妙的时刻。”
  14. Ada : 要理解这个时刻，我们得回到她的童年。苏姿丰出生在一个讲台湾闽南语的家庭，很小就来到了美国。
  15. Alan : 据美国消费者新闻与商业频道CNBC报道，全家移民，是为了让身为数学家的父亲，能去纽约读研究生。
  16. Ada : 而且父亲回到家也不放过数学！她对《福布斯》讲过：父亲会在饭厅的餐桌上，考她乘法口诀。
  17. Alan : 那她的母亲呢？
  18. Ada : 母亲先当会计，后来创业，尽管英语不太流利，还是做起了一家规模达数百万美元的进出口公司。苏姿丰说，母亲给了她巨大的鼓舞。
  19. Alan : 父母还从她七岁起，就让她参加钢琴比赛，每天要练好几个小时。后来，为了去录取极其严格的布朗克斯科学高中，她每天要在路上花四个小时。
  20. Ada : 四个小时！她1986年毕业，十七岁就进了麻省理工学院。
  21. Alan : 她选了电气工程……因为那是最难的专业。
  22. Ada : 转折点是一次X射线光刻的实习，用的是两英寸的晶圆，也就是制造芯片用的硅片。很多实验都失败了，但这项技术的巨大威力让她着迷。
  23. Alan : 这份着迷很快变成了职业：先是德州仪器，然后在IBM待了将近十三年。
  24. Ada : 在IBM，她2000年成为首席执行官郭士纳的技术助理。她还参与了铜互连技术，以及PlayStation 3游戏机里的Cell处理器。
  25. Alan : 接着，她2007年加入飞思卡尔，担任首席技术官，2012年加入AMD。2014年10月8日，她接掌了公司。2024年，她对《时代》周刊说：“AMD是我的机会。”
  26. Ada : 这个机会，可不是一目了然的，对吧？
  27. Alan : 完全不是。据《时代》周刊报道，当时AMD的股价在三美元上下徘徊。而AMD在数据中心芯片里的份额小得可怜，管理层干脆把它当成零。
  28. Ada : 当时，有些董事想转向手机芯片。她拒绝了：“我们必须押注在自己擅长的事情上。”
  29. Alan : 她对董事会和股东预告：复兴需要五年。随后是Zen架构，2017年又推出了锐龙Ryzen和霄龙EPYC处理器，还押注了小芯片设计。2022年，AMD的市值首次超过英特尔。
  30. Ada : 在这段历程背后，还有一些意想不到的故事。先说中文课上的C。
  31. Alan : 讲讲看。
  32. Ada : 2020年，她对《奥斯汀女性》杂志说，在中文学校里，她写毛笔字永远拿C，让父母很失望。而她选了麻省理工学院，几乎同样让他们失望。
  33. Alan : 麻省理工学院，家里的第二大失望。太逗了。第二个故事，是在麦当劳的取餐车道上招人。
  34. Ada : 在取餐车道上？
  35. Alan : 2014年10月，Forrest Norrod刚从戴尔离职。他开车排在麦当劳的取餐车道上，等着一份四分之一磅牛肉堡，这时接到了苏姿丰的电话，她想请他加盟。
  36. Ada : 第三个故事，是英伟达的老板黄仁勋，也就是她最大的对手。两人是远房亲戚，亲缘来自黄仁勋的母亲那一边。
  37. Alan : 他们是一起长大的吗？
  38. Ada : 不是。2024年十二月，她对彭博社说：“没有家庭聚餐。这是个有趣的巧合。”2026年10月8日，两人一同在华盛顿受奖。
  39. Alan : 除了这些巧合，她怎么看未来？2025年8月，她在《连线》杂志上说：“我是个彻头彻尾的技术乐观主义者。但在如何实现的问题上，我很务实。”
  40. Ada : 那关于AGI，也就是通用人工智能呢？
  41. Alan : 还是在《连线》上：“我相信AGI，但我不相信AI会比人更聪明这种说法。我也不是个爱谈世界末日的人。”
  42. Ada : 我最喜欢的一句，出自她2026年5月28日在麻省理工学院的毕业典礼演讲：“技术本身不会决定未来的样子。决定未来的是人。”
  43. Alan : 还有，10月6日在台北，被问到末日情景时，她说：“我真心相信，AI对这个世界有极大的好处。”
  44. Ada : 这种乐观并非人人认同，AMD的一些决定也招来批评，尤其是和特朗普政府的关系。
  45. Alan : 据《新共和》杂志报道，AMD同意把对中国销售处理器收入的百分之十五交给美国政府，换取出口许可证。
  46. Ada : 2025年，她在《连线》杂志上说，她不想对一般的社会议题表态，因为她认为，那不是自己能创造价值的地方。
  47. Alan : 另一种批评，是担心AI泡沫。有些观察人士指责这是资金在圈子里转来转去的循环融资，并举出AMD给OpenAI的认股权证，作为OpenAI完成部署目标的回报。
  48. Ada : 2025年十二月，她回应说：“从我的角度看，绝对不是，”并称这些担忧“有些夸大”。
  49. Ada : 我们很想问她几个问题。Lia，Choucroute Citron的AI联合主持人，来和我们一起了。你会问什么？
